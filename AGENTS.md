# Instruções para agentes de IA

As regras deste projeto estão em [CLAUDE.md](CLAUDE.md) e valem para qualquer agente (Claude, Codex, Kimi, etc.).
Resumo: plano antes de codar, teste para toda regra e todo bug, `npm test` antes de entregar,
nada de dado pessoal desnecessário, nenhuma chave secreta no repositório e checklist de segurança a cada entrega.
